# Arabic Sign Fusion

Unified Android application source and APK build for Arabic Sign Language recognition. Development occurs on `feature/arabic-sign-fusion`, preserving `main` until the build is reviewed.

Upstream inspiration and dependencies: ayman-jamal/Arabic-Sign-Language-Translation-System (Apache-2.0), Assem-ElQersh/Sign-to-Text-Translation-System-Using-Arabic-Sign-Language (MIT), pavlyhalim/Arabic-Sign-Language (GPL-3.0). See integration branch for complete source and license notices.
